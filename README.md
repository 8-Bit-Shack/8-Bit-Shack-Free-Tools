# 8-Bit Shack: Free Tools

Welcome to the **8-Bit Shack Free Tools** repository!

This repository contains a collection of free Apple II programming tools published by **8-Bit Shack** and its contributors. Each tool is a folder with its disk images, documentation, the Applesoft BASIC and assembly source where available, and every file extracted from the disks.

All tools are available to download and use for free.

## Available Tools

| Title | Description | Download |
|---|---|---|
| **DOLORES** | Double Lo-Res graphics library for Applesoft BASIC on the Apple //e: plot, lines, rectangles, circles, flood fill, page copy, mixed mode, double buffering and sprites, through the & command. Three versions with demos and the manual. | [ZIP](https://github.com/8-Bit-Shack/8-Bit-Shack-Free-Tools/releases/latest/download/tool_dolores.zip) |
| **FFedit and FrameAnim** | Double Lo-Res frameset editor and the matching animation player with MockingBoard music for Applesoft BASIC. | [ZIP](https://github.com/8-Bit-Shack/8-Bit-Shack-Free-Tools/releases/latest/download/tool_ffedit.zip) |
